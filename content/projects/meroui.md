## About this project

**meroUI** is a hand-built component library and docs site with a strict
monochrome design system — canvas, ink, and one zinc ramp. Every component ships
as a single source file you copy into your project and fully own: no runtime
dependencies, no config, no lock-in.

The site itself is built entirely from meroUI's own components — the hero, the
docs shell, and the templates gallery.

### Features

- **Ship faster** — drop-in components for the Next.js + React stack
- **Zero dependencies** — no runtime deps, lean bundles
- **Dark by default** — a black-and-white system built for dark UIs
- **Accessible** — keyboard-first, screen-reader-ready, AA+ on every surface
- **Tested** — unit-tested and prod-verified
- **MIT licensed** — free for side projects, client work, and commercial products
- **Interactive landing** — a draggable 3D component ring, live demos, and a real package-manager install terminal

### Components

Twelve components across three groups:

- **Feedback** — Button, Badge, Progress, Skeleton, Toast
- **Controls** — Input, Toggle, Tabs
- **Display** — Card, Table, Modal, Tooltip

### Tech stack

| Layer | Choice |
| --- | --- |
| **Framework** | Next.js (App Router, Turbopack) |
| **UI** | React 19, TypeScript |
| **Styling** | Tailwind CSS v4, custom monochrome design tokens |
| **Animation** | GSAP + ScrollTrigger |
| **Hosting** | Cloudflare Workers + Workers Assets via OpenNext |
